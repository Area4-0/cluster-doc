Quickstart#

Prerequisites#

Users are expected to have familiarity with the following concepts:

  • Operating systems (preferably Linux)
  • File systems and directories
  • Command-line interfaces (CLI)
  • Remote access tools (e.g., SSH)

Advanced system administration skills are not required, but will be helpful.

Use the cluster#

  1. Request access to the VPN and to the required cluster, here is described how to do it.
  2. Ask your supervisor to assign to you a MAC address to be used by your containers. Without this, you will not be able to create one. Your supervisor can use this website to assign you a MAC address: https://padfy.campusfc.unibo.it/.
  3. Configure your environment to use the VPN, following the guide received by email.
  4. Go to https://andromeda.apice.unibo.it:8006 and log in with institutional credentials (the same used for the VPN).
  5. Deploy your container following good practices.

Note

The connection is provided by internal SSL certifiates, modern browsers try to block the connection to them. You have to explicitly declare, the first time you enter the URL described above, that you want to access the website.
